# Python-IT-support-tickets--analytics
IT Support Tickets And SLA Analytics using Python Pandas, NumPy, Matplotlib and Seaborn

Project Overview

This project analyses IT support tickets to monitor ticket volume, resolution performance, SLA compliance, and support team workload.

Tools Used

- Python
- Pandas
- NumPy
- Google Colab
- Matplotlib
- Seaborn

Key Analysis

- Monthly ticket trends
- Ticket status analysis
- Average resolution time
- SLA compliance
- Priority-wise performance
- Support team workload
- Overdue open ticket analysis

Project Structure

- data/
- outputs/
- screenshots/
- Project_5_IT_Support_Ticket_Analytics.ipynb

Outputs

- ticket_analysis.csv
- team_workload.csv
- ticket_status_summary.csv

Conclusion

This project helps identify ticket backlogs, monitor SLA performance, and understand support team efficiency using Python.
